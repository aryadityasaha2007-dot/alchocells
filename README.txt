1. Install Node.js 18 or newer (https://nodejs.org), then check: node -v
2. Save your App.jsx (the code you pasted) as:  src/App.jsx
3. In this folder run:   npm install
                         npm run dev
4. Open the address it prints (normally http://localhost:5173)
Optional: node src/packModel.test.mjs   (runs the model tests)
